# Фаза 2: Перехват файлов, Tool Use и Умный Скроллинг

Этот план описывает вторую стадию разработки локального API-прокси для ChatGPT, которая добавит поддержку обмена файлами, использования инструментов (Tool Use) IDE и детерминированной работы с историей.

## Открытые вопросы (User Review Required)

> [!IMPORTANT]
> **Маршрутизация файлов в IDE:** Когда прокси скачает файл от ChatGPT (например, `lode_runner_final.py`), как именно мы должны вернуть его в IDE?
> 1. Просто вставить весь исходный код файла текстом в конец ответа (чтобы IDE сама его распарсила).
> 2. Сформатировать его как вызов `tool_call` (если IDE запрашивала создание файла через Tool Use).
> *Рекомендуемый вариант: Вариант 1 для начала, так как он самый универсальный и сработает для любых IDE, даже если они не просили файл явно.*

## Предлагаемые изменения

### W:\_python\APIPROXY\browser_manager.py

В ядре управления браузером будут сделаны самые масштабные изменения.

#### [MODIFY] [browser_manager.py](file:///W:/_python/APIPROXY/browser_manager.py)
- **Изоляция загрузок (Download Behavior):** При инициализации браузера (`setup_profile` / `start_browser`) мы отправим CDP-команду `Browser.setDownloadBehavior`, которая перенаправит все скачивания из папки "Загрузки" в `W:\_python\APIPROXY\temp_downloads`.
- **Авто-скроллинг:** В функции отправки промпта мы добавим жесткий фокус на `#prompt-textarea` и скроллинг страницы вниз (`window.scrollTo(0, document.body.scrollHeight)`) перед попыткой сбора ответа. Это исправит баг "ленивой загрузки" (Virtualization), когда нужный чат или кнопка файла прятались вне экрана.
- **Детектор файлов:** После завершения генерации ответа (когда кнопка "Stop" исчезает), скрипт найдет в последнем сообщении кнопки с тегом `<code>` и кликнет по ним.
- **Сборщик файлов (Extractor):**
  1. Скрипт проверит папку `temp_downloads`. Если файл появился — прочитает его, присоединит к ответу в виде `\n\n[Скачанный файл: имя]\n\`\`\`python\nкод\n\`\`\`` и удалит файл с диска.
  2. Если папка пуста, скрипт попытается извлечь код из Canvas (`.cm-content`).

### W:\_python\APIPROXY\api_server.py

Доработка FastAPI сервера для работы со структурами IDE.

#### [MODIFY] [api_server.py](file:///W:/_python/APIPROXY/api_server.py)
- **Поддержка Tool Use в промптах:** Когда IDE присылает запрос с полем `tools` (например, список доступных функций), сервер будет перехватывать этот JSON и превращать его в текстовую приписку к системному промпту (например, *"Ты можешь использовать следующие инструменты, отвечай в формате JSON: ..."*). Это позволит ChatGPT понимать системные инструменты IDE без родной поддержки API-тулзов.
- **Хранение URL чатов:** Модернизация структуры `ChatState`. Вместо того, чтобы в будущем искать старые чаты в боковой панели, `ChatState` будет сохранять точный URL-адрес (`href`) каждого начатого чата в памяти, привязывая его к хэшу диалога.
